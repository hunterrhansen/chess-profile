# Saved design prototypes

These static game-review prototypes capture design exploration for later migration.
They are reference material; the running web and mobile apps use their own source.

- `game-review-wireframe.html` and `game-review-preview.html`: initial game review.
- `review-branching-wireframe.html` and `review-branching-preview.html`: variations
  and branching review.
- `review-variation-desktop.png`: desktop variation reference.

Open the HTML files in a browser to view them. Some preview fonts and icons load
from public CDNs and require an internet connection.
